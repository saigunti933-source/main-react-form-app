
# Main React Form App

A Student Registration Form developed using React.js and Vite.

## Features

- Student name input
- Student age input
- Gender selection
- Branch selection
- Form submission
- Display submitted student details
- Clear form functionality
- React useState
- Event handling using onChange and onSubmit

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
